Computer science student at Scaler School of Technology, exploring backend development, databases, and computer networks.

## Selected projects

### [Search Typeahead](https://github.com/Aana-1025/Search-Typehead)
Prefix-based search suggestions with PostgreSQL storage, Redis caching, batched search-count updates, and a React interface.

**Built with:** Java · Spring Boot · PostgreSQL · Redis · React

[Explore the project](https://github.com/Aana-1025/Search-Typehead#readme) · [Architecture](https://github.com/Aana-1025/Search-Typehead/blob/main/docs/architecture.md)

### [HTTP in Binary](https://github.com/Aana-1025/http-in-binary)
A TCP client and server for file transfer using a custom binary protocol. Includes frame parsing, persistent connections, path validation, and protocol tests.

**Built with:** Python · Sockets · Standard-library testing

[Explore the project](https://github.com/Aana-1025/http-in-binary#readme) · [Protocol specification](https://github.com/Aana-1025/http-in-binary/blob/main/SPEC.md)

### [AuditGuard](https://github.com/Aana-1025/AuditGuard-AI)
An expense-auditing prototype with rules for suspicious transactions, a review dashboard, and a simulated audit workflow.

**Built with:** Python · FastAPI · React

[Explore the project](https://github.com/Aana-1025/AuditGuard-AI#readme)
